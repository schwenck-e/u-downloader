Quick Installation

Choose your platform and get started in minutes

Debian/Ubuntu 
sudo apt update
sudo apt install python3-pip ffmpeg curl
pip3 install yt-dlp
git clone https://github.com/schwenck-e/u-downloader.git
cd u-downloader
chmod +x downloader.sh
Arch Linux 
sudo pacman -S yt-dlp ffmpeg curl git
git clone https://github.com/schwenck-e/u-downloader.git
cd u-downloader
chmod +x downloader.sh
Homebrew Tap (recommended) 
brew tap schwenck-e/tap
brew install u-downloader

✓ Installs everything (u-downloader + dependencies)
✓ Global command available: u-downloader

Homebrew (dependencies + manual clone) 
brew install yt-dlp ffmpeg
git clone https://github.com/schwenck-e/u-downloader.git
cd u-downloader
chmod +x downloader.sh
Manual Installation (macOS 12 or without Homebrew) 
git clone https://github.com/schwenck-e/u-downloader.git
cd u-downloader
chmod +x install-dependencies.sh
./install-dependencies.sh
FreeBSD 
pkg install yt-dlp ffmpeg git
git clone https://github.com/schwenck-e/u-downloader.git
cd u-downloader
chmod +x downloader.sh

Usage Examples

Simple commands for powerful results

Download a Video

# If installed via Homebrew tap:
u-downloader https://youtube.com/watch?v=VIDEO_ID

# Or manual installation:
./downloader.sh https://youtube.com/watch?v=VIDEO_ID

Download in Specific Quality

# Homebrew:
u-downloader -q 1080 https://vimeo.com/VIDEO_ID

# Manual:
./downloader.sh -q 1080 https://vimeo.com/VIDEO_ID

Extract Audio Only (MP3)

# Homebrew:
u-downloader -a https://soundcloud.com/track

# Manual:
./downloader.sh -a https://soundcloud.com/track

Download Entire Playlist

# Homebrew:
u-downloader -p https://youtube.com/playlist?list=ID

# Manual:
./downloader.sh -p https://youtube.com/playlist?list=ID

Command Options

Option Description
-q, --quality Video quality (best, 1080p, 720p, 480p)
-o, --output Output directory (default: ~/Downloads)
-p, --playlist Download entire playlist
-a, --audio-only Extract audio only (MP3)
-c, --cookies Use browser cookies (safari, chrome, firefox)
-u, --update Update yt-dlp to latest version
-v, --verbose Show detailed output
-h, --help Show help message
