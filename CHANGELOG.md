# Changelog - u-downloader

## [1.0.0] - 2026-04-06

### 🎉 Initial Release

Complete rebranding from "u-downloader" to **u-downloader**.

#### Features
- ✅ **Cross-platform** - Linux, macOS, BSD, WSL support
- ✅ **1872+ sites supported** - YouTube, Vimeo, Instagram, TikTok, Facebook, etc.
- ✅ **Professional interface** - Docker-style animated progress bars
- ✅ **Smart validations** - URL format and disk space checking
- ✅ **Playlist organization** - Auto-creates subfolders for playlists
- ✅ **Multiple formats** - Video (H.264/AAC) and audio (MP3)
- ✅ **Browser authentication** - Optional cookie support
- ✅ **Auto-update** - Built-in yt-dlp updater
- ✅ **Detailed feedback** - Download time and file size
- ✅ **Graceful interruption** - Clean Ctrl+C handling

#### Technical Details
- 334 lines of portable Bash code
- POSIX-compliant commands
- Zero dependencies beyond yt-dlp and ffmpeg
- ANSI terminal colors and animations
